# VX brand assets

Use `vx-symbol-light.svg` and `vx-lockup-light.svg` on light backgrounds (Graphite #101713). Use the dark variants on dark backgrounds (Chartreuse #D7FF3F). Preserve the aspect ratio, spacing and colors. The symbol supports sizes of 16 px or more; display the lockup at least 150 px wide.

`vx-avatar-dark.png` is the 512 px square organization avatar asset. The transparent SVGs contain vector paths and outlined lettering with no fonts, raster images or external resources. These are the production brand files approved for VX.
