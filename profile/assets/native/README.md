These additive files reconstruct VX's approved v2 identity as named, independently editable Inkscape layers, groups and paths. The active organization logo and avatar files remain unchanged. The symbol has four angular path components; the custom lowercase wordmark has two paths and no font dependency.

Open `vx-master.inkscape.svg` as the main editable lockup. The dedicated symbol, light/dark, currentColor and 16/24 px sources are separate editable files. `typed-plans/` contains the 13 reusable bounded DCC-MCP build inputs. They preserve the approved reference geometry from [999245a](https://github.com/vx-org/.github/commit/999245ac3808be05bb0610673310020d29bf3cb2).

The actual production chain was typed DCC-MCP input, Inkscape-hosted inkex effect, native document commit, native PNG/Plain SVG export, and native reopen/query. Inkscape was 1.4.4; the adapter source was [8551608](https://github.com/dcc-mcp/dcc-mcp-inkscape/tree/8551608a1cdb1331ca03bb3110ef6473e0fb16cc). Retained local checks correlate each invocation; they are not cryptographic host attestation. CLI calls requested auto transport with an enforced gateway control route; these records do not claim an explicit MCP transport session.

The 39 initial build/export/reopen calls passed, and the 33 additional native exports passed. Nine transparent PNG sizes per light/dark palette are available: 1024, 512, 256, 128, 64, 48, 32, 24 and 16 px. Genuine ICO and ICNS are separately assembled containers holding exact native PNG bytes, without resizing or re-encoding. They are not native Inkscape export formats. See [variants](../variants/README.md), [manifest](../manifest.json), [brand rights](../BRAND-RIGHTS.md), and the sanitized `evidence/` records.

QA checks passed for approved paths, native layers/groups, proportions, transparent PNG dimensions, container headers/payloads, light/dark display backgrounds and real 16/24 px observations. The small files preserve the approved symbol geometry; no unobserved optical correction is claimed. Chromium 151.0.7922.34 verified all eight inline currentColor theme contexts. Their screenshot/report in `qa/` is browser QA, not a native artwork export.

These additions are review sources and variants, not a declaration of final user approval or a replacement of the current production identity.
